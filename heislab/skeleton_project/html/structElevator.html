Detailed Description

Defines an Elevator struct to store values.

This struct holds information about an elevator, including its current floor, movement direction, and a queue of requested destinations.

Parameters
current_floorThe current floor of the elevator.
moving_directionThe current movement direction, which can be either DIRN_UP or DIRN_DOWN.
in_motionTell whether or not the elevator is in motion at the current moment.
request_queueA queue of destination requests that helps the elevator determine where to go next.
queue_sizeThe current number of elements in the destination queue.
queue_capacityThe maximum number of destination requests the queue can hold.
