Detailed Description

Defines an Elevator struct to store values.

This struct holds information about an elevator, including its current floor, movement direction, and a queue of requested destinations.

Parameters
_currentFloorThe current floor of the elevator.
_movingDirectionThe current movement direction, which can be either DIRN_UP or DIRN_DOWN.
_destinationQueueA queue of destination requests that helps the elevator determine where to go next.
_queueSizeThe current number of elements in the destination queue.
_queueCapacityThe maximum number of destination requests the queue can hold.
