Sorts an array of elevator requests using the bubble sort algorithm. 

This function sorts an array of elevator requests based on their floor numbers. The sorting order is determined by the current direction of the elevator\+:
\begin{DoxyItemize}
\item If the elevator is moving down (i.\+e., {\ttfamily D\+I\+R\+N\+\_\+\+D\+O\+WN}), the requests are sorted in descending order.
\item If the elevator is moving up (i.\+e., {\ttfamily D\+I\+R\+N\+\_\+\+UP}), the requests are sorted in ascending order.
\end{DoxyItemize}

The function uses the {\ttfamily qsort()} function for sorting and then reverses the order if the elevator is moving down. The bubble sort algorithm is conceptually followed, but it is implemented using the more efficient {\ttfamily qsort()} for initial sorting.

\item {\ttfamily D\+I\+R\+N\+\_\+\+UP}\+: Sorts the array in ascending order (from low to high floor).
