## Arrows (for navigation)

| Symbol | Unicode | Meaning                        |
| ------ | ------- | :------------------------------ |
| ➜      | U+279C  | Right arrow (common for links) |
| ➠      | U+27A0  | Right arrow (alternative)      |
| ➥      | U+27A5  | Down-right arrow               |
| ⬅      | U+2B05  | Left arrow                     |
| ➡      | U+27A1  | Right arrow                    |
| ⬆      | U+2B06  | Up arrow                       |
| ⬇      | U+2B07  | Down arrow                     |
